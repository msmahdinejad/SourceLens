# Charge While You Shop demo questions

Install the optional corpus with `paperlens demo`, then select the **Charge While You Shop**
workspace.

- How should driver preferences and expected dwell time shape charging at retail destinations? Cite every major claim.
- Compare the methods, evidence, assumptions, and limitations across the two sources.
- Which findings come from consumer evidence, which are technical recommendations, and which remain uncertain?
- Build a timeline from the 2021 consumer study to the 2024 transatlantic recommendations.
- What evidence should a decision-maker require before funding chargers at a new retail site?
- Create an evidence table with driver need, infrastructure choice, interoperability or grid consideration, and limitation.

These prompts exercise multi-search planning, page citations, cross-document synthesis,
uncertainty, abstention, and Studio outputs without relying on a demo-only answer path.
