# Charge While You Shop demo walkthrough

1. Start from a fresh empty workspace and run `paperlens demo`.
2. Show the two checksum-verified studies moving through extraction and indexing.
3. Add one official DOE or Joint Office charging page with Search and keep its source URL visible.
4. Ask how driver needs, dwell time, and interoperability should shape retail charging, requiring citations.
5. Open two page-evidence cards and distinguish consumer evidence from technical recommendations.
6. Generate a report, flashcards, an editable slide deck, an audio overview, and a video overview.
7. Open Studio live events, media credits, captions, and the downloadable artifacts.

Use only real application output. Licensed media should come through the configured media API,
retain provider provenance, and use queries listed in `docs/demo/new-source-research.md`.
